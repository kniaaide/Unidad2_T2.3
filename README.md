# Unidad2_T2.3

Proyecto académico de la **Unidad 2, actividad T2.3**, desarrollado en C# con Windows Forms.

## Contenido

La solución incluye una aplicación gráfica (`MainForm.cs`) y una carpeta `Ejercicios` para organizar los ejercicios de la unidad.

## Requisitos

- Visual Studio con soporte para C# y Windows Forms.
- .NET compatible con el archivo `Unidad2_T2.3.csproj`.

## Ejecución

Abre `Unidad2_T2.3.sln` en Visual Studio y ejecuta el proyecto.

## Estado

Repositorio de práctica académica.
